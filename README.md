# AI Spend Policy Setup Assistant

Product Faculty capstone prototype. Reads messy spend-policy documents, proposes rules, asks a person the questions only a person can answer, and exports a reviewed rule set (JSON, CSV, clean text).

- AI reads and proposes. Code checks quotes, approver lists, authority and coverage. A person decides.
- All companies, people and amounts are fictional. No API keys are stored in this repo.
- The page opens in a labelled sample mode. Real AI needs you to connect your own key in the page.

## Run it
Open `index.html` in a browser. No build step.

## Limits
AI output varies between runs. For your own documents the tool stops at rules, questions and the export. PDF quotes cannot be checked; use a .txt copy.
